# Movie-Recommendation-System-using-Collaborative-Filtering

A simple Movie Recommendation System built using Python and Collaborative Filtering. The project recommends movies based on user ratings from the MovieLens dataset.

## About

This project uses Collaborative Filtering to find users with similar interests and recommend movies they may enjoy. It demonstrates the basic working of recommendation systems used by streaming platforms.

## Features

- Load MovieLens dataset
- Data preprocessing
- User-Movie Utility Matrix
- Collaborative Filtering
- Cosine Similarity
- Personalized movie recommendations

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Dataset

MovieLens Dataset

Files used:
- movies.csv
- ratings.csv

## How to Run

1. Clone the repository
2. Install required libraries

```bash
pip install pandas numpy scikit-learn
```

3. Open Jupyter Notebook

```bash
jupyter notebook
```

4. Run

```
recommendation_system.ipynb
```
